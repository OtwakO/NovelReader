# Documentation Archive

Everything under this directory is historical and non-authoritative.

Use current code/tests and the routing documents linked from [`PLAN.md`](../../PLAN.md) for present behavior. Archived material is preserved for provenance, superseded rationale, completed audit evidence, and recovery of decisions not obvious from Git history.

- `audits/` — completed cleanup and compatibility audit snapshots.
- `designs/` — superseded design/contract documents.
- `history/` — chronological development logs and old plan snapshots.
- `plans/` — completed or abandoned implementation checklists that predate the current plan lifecycle.
- `research/` — historical analyses whose current-state claims are stale but whose evidence remains useful.

Do not update archived files merely because current implementation changes. If an archived decision is reversed, record current truth in the appropriate architecture, roadmap, decision, or active plan and link back only when the history is useful.
