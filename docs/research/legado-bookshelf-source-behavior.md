# Legado bookshelf/source behavior

**Scope.** Primary-source review of official `gedoor/legado` code at commit [`ee5ef0e`](https://github.com/gedoor/legado/commit/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4) (2025-08-28; the repository’s later tip replaced the code with a notice).

## Findings

1. **Same title + author resolves to one shelf row, not a duplicate.** `Book` declares `bookUrl` as its primary key *and* a unique Room index on `(name, author)` (`app/src/main/java/io/legado/app/data/entities/Book.kt`, `Book`, [lines 34–57](https://github.com/gedoor/legado/blob/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4/app/src/main/java/io/legado/app/data/entities/Book.kt#L34-L57)). More importantly, opening a search result first calls `BookDao.getBook(name, author)` and substitutes the existing shelf `Book` before consulting the result’s `bookUrl` (`BookInfoViewModel.initData`, [lines 57–75](https://github.com/gedoor/legado/blob/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4/app/src/main/java/io/legado/app/ui/book/info/BookInfoViewModel.kt#L57-L75)). Thus exact normalized title/author is the logical shelf identity; the result does not become a second shelf book. `addToBookshelf` also looks up `(name, author)` to carry reading progress before saving ([lines 421–443](https://github.com/gedoor/legado/blob/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4/app/src/main/java/io/legado/app/ui/book/info/BookInfoViewModel.kt#L421-L443)).

2. **“Change source” searches enabled sources for the current book name, optionally checking author.** `ChangeBookSourceViewModel.initData` receives `name` and strips author decorations; `search` calls every selected `BookSource` with the name and accepts exact `fName == name`, plus `fAuthor.contains(author)` when `changeSourceCheckAuthor` is enabled ([lines 152–163](https://github.com/gedoor/legado/blob/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4/app/src/main/java/io/legado/app/ui/book/changesource/ChangeBookSourceViewModel.kt#L152-L163), [260–280](https://github.com/gedoor/legado/blob/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4/app/src/main/java/io/legado/app/ui/book/changesource/ChangeBookSourceViewModel.kt#L260-L280)). Cached candidates are queried by exact name, author substring, enabled source, and optional source group; in-book filtering searches `originName` or latest-chapter title (`SearchBookDao.changeSourceByGroup` / `changeSourceSearch`, [lines 15–44](https://github.com/gedoor/legado/blob/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4/app/src/main/java/io/legado/app/data/dao/SearchBookDao.kt#L15-L44)). A candidate’s source identity is `origin` (the source URL/key), while its edition identity is `bookUrl`; selecting it migrates state, deletes the old book row, and inserts the candidate (`BookInfoViewModel.changeTo`, [lines 360–374](https://github.com/gedoor/legado/blob/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4/app/src/main/java/io/legado/app/ui/book/info/BookInfoViewModel.kt#L360-L374)).

3. **The UI displays source name, not source URL.** Both the book-info screen and change-source rows bind `originName` to the visible source label (`BookInfoActivity.showBook`, [lines 335–340](https://github.com/gedoor/legado/blob/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4/app/src/main/java/io/legado/app/ui/book/info/BookInfoActivity.kt#L335-L340); `ChangeBookSourceAdapter.convert`, [lines 54–64](https://github.com/gedoor/legado/blob/ee5ef0e6ba05f47aa01568fbbe100694b0f9ced4/app/src/main/java/io/legado/app/ui/book/changesource/ChangeBookSourceAdapter.kt#L54-L64)). The current candidate is check-marked by matching the old `bookUrl`, not by the displayed label.
